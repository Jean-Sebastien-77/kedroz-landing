# kedroZ · maquette de landing

Maquette haute fidélité de la landing kedroZ (ex Kedros), logiciel pour les études notariales de leZèbre Tech.

- `index.html` : la landing, teinte sauge
- `planche-teintes.html` : comparaison de teintes sur la vraie page (`?set=couleurs` pour la seconde planche)
- `assets/kedroz-cedre.svg` : picto cèdre
- `NOTE-kedroz.md` : choix de design et points à valider

Fichiers statiques, sans dépendance : ouvrir `index.html` dans un navigateur. Données affichées fictives. Le formulaire n'envoie rien.
